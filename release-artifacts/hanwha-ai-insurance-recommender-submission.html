01. Service Overview

서비스 개요

문제 정의

보험 상품은 종류와 설명이 많아 사용자가 첫 탐색 단계에서 어떤 상품부터 봐야 할지 결정하기 어렵습니다.

특히 모바일 환경에서는 긴 상품 목록보다 짧고 직관적인 추천 흐름이 필요합니다.

해결 접근

얼굴 인식으로 추정한 나이·성별을 사용자가 직접 확인하고, 규칙 기반 추천 엔진이 2~4개의 상품을 우선 노출합니다.

추천 상품 카드는 썸네일, 추천 이유, 공식 출처 링크를 함께 제공합니다.

1
카메라 기반 진입얼굴 입체 스캔으로 나이·성별 추정
2
사용자 확인추정값을 그대로 쓰지 않고 수정 가능
3
상품 큐레이션연령대별 한화손보 상품 추천
4
간단한 이용 경험가입 전 후보 상품을 빠르게 확인

핵심 가치

복잡한 보험 탐색의 첫 단계를 “나에게 맞는 후보 상품 4개 확인”으로 줄여, 사용자가 더 빠르게 공식 상품 정보를 살펴볼 수 있게 합니다.

05. Service Composition

서비스 구성

화면 경험
  • 서비스 목적을 첫 화면에서 안내
  • 카메라 시작과 수동 입력을 함께 제공
  • 모바일과 PC 화면에 맞춘 구성
  • 상품별 일러스트 썸네일 제공
얼굴 분석 흐름
  • 정면과 좌우 방향을 단계별로 안내
  • 나이·성별 추정값을 화면에 표시
  • 추천 전 사용자가 직접 확인
  • 실패 시 수동 입력으로 대체
추천 구성
  • 연령대와 성별 확인값 반영
  • 2~4개의 상품 후보 제공
  • 카드별 추천 이유 표시
  • 공식 출처 링크 연결

06. Recommendation Logic

추천 룰

얼굴 인식 결과가 직접 상품을 고르는 구조가 아니라, 사용자가 확인한 나이·성별을 기준으로 정적 규칙이 상품 후보를 선택합니다.

운영 안전성

  • 계약 가능 여부 판단 없음
  • 보험료 산출 없음
  • 상품 추천은 공식 출처 탐색을 돕는 후보 제시
  • 카메라 실패 시 수동 입력으로 대체
