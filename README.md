# 한화손보 AI 생체정보 기반 상품 추천

카메라로 얼굴을 인식해 추정한 나이와 성별을 사용자가 확인한 뒤, 한화손보 추천 상품을 보여주는 브라우저 기반 웹 앱입니다.

## 배포 주소

- https://qwlake.github.io/insu-recommender/

## 실행

```bash
npm install
npm run dev
```

브라우저에서 Vite 개발 서버 주소를 열고 화면의 버튼으로 카메라 권한을 허용합니다.

> 모바일/브라우저에 따라 카메라 사용에는 HTTPS 또는 localhost가 필요할 수 있습니다.

## 검증

```bash
npm test
npm run build
```

## 추천 룰 로직

추천 로직은 `src/recommendations.js`의 정적 규칙을 따릅니다. 얼굴 인식 모델이 직접 상품을 고르지 않고, 얼굴 인식 결과에서 얻은 나이/성별을 기준값으로 변환한 뒤 미리 정의한 상품 목록을 선택합니다.

### 1. 입력값 정리

- 얼굴 인식 결과 또는 수동 입력값에서 `나이`, `성별`을 받습니다.
- 얼굴 인식 결과가 20세 미만으로 나오면 추천 기준에서는 최소 `20세`로 노출합니다.
- 수동 입력과 확인 입력도 최소 `20세`부터 받습니다.
- 연령대는 `src/utils/ageBucket.js` 기준으로 아래처럼 나눕니다.

| 나이 | 연령대 |
|---:|---|
| 0~29 | 20대 |
| 30~39 | 30대 |
| 40~49 | 40대 |
| 50~59 | 50대 |
| 60+ | 60대 이상 |
| 숫자 아님 / 음수 | 연령대 미확인 |

### 2. 연령대별 기본 추천 상품

| 연령대 | 추천 상품 순서 |
|---|---|
| 20대 | 캐롯 해외여행보험 → 한화실손의료보험(갱신형) → 캐롯 운전자보험 → 치아안심보험 |
| 30대 | 캐롯 운전자보험 → 한화실손의료보험(갱신형) → 다이렉트 119주택화재보험 → 치아안심보험 |
| 40대 | 다이렉트 내가고른암보험 → 한화 더건강한 한아름종합보험(무) → 캐롯 운전자보험 → 다이렉트 119주택화재보험 |
| 50대 | 한화 더건강한 한아름종합보험(무) → 다이렉트 내가고른암보험 → 다이렉트 119주택화재보험 → 치아안심보험 |
| 60대 이상 | 한화 더 경증 간편건강보험Ⅱ(세만기형)(무) → 한화 더건강한 한아름종합보험(무) → 다이렉트 내가고른암보험 → 다이렉트 119주택화재보험 |
| 연령대 미확인 | 다이렉트 내가고른암보험 → 캐롯 운전자보험 → 다이렉트 119주택화재보험 |

### 3. 성별 보정

- 성별이 `여성`이고 연령대가 20대~50대이면 `한화 시그니처 여성 건강보험 4.0(무)`을 추천 목록 맨 앞에 추가합니다.
- 성별이 `남성` 또는 `선택 안 함`이면 여성 전용 상품은 추천 목록에서 제외합니다.

### 4. 최종 출력 규칙

- 중복 상품 ID를 제거합니다.
- 최대 4개까지만 보여줍니다.
- 결과가 2개 미만이면 일반 상품으로 보충해 최소 2개를 보여줍니다.

### 5. 추천 이유 문구

상품 카드의 추천 이유는 `RECOMMENDATION_REASONS`에 정의되어 있습니다.

예시:

- 20대 + 여행: `20대는 여행과 이동 계획이 늘기 쉬워, 여행 중 생기는 변수에 대비하는 상품으로 추천합니다.`
- 20대 + 실손: `20대는 병원 이용이나 갑작스러운 치료비 부담을 미리 살펴두면 좋아, 실손의료보험을 함께 추천합니다.`
- 30대 + 운전자: `30대는 출퇴근과 일상 이동으로 운전 시간이 늘기 쉬워, 운전자 상품을 함께 추천합니다.`
- 40대 + 종합 건강: `40대부터는 암·뇌·심장 같은 주요 질병을 함께 점검할 필요가 커져, 종합 건강 상품을 추천합니다.`
- 60대 이상 + 간병/노후: `60대 이상은 치료 이후 간병비와 가족 부담까지 고려할 일이 많아져, 노후 간병 준비를 확인하는 상품으로 추천합니다.`

## 상품 데이터

상품 카드는 한화손보/한화다이렉트 공식 공개 페이지에서 확인한 상품명을 바탕으로 만든 정적 데이터입니다. 구현 시점 확인일은 `src/products.js`의 `sourceCheckedAt`에 기록했습니다.

변액보험, 연금·저축성 상품처럼 현재 구현 과정에서 구체 상품명·판매기간·공식 자료까지 검토하지 않은 상품은 추천 목록에 넣지 않습니다. 60대 이상 노후 니즈는 공식 상품 페이지에서 `노후 준비`, `간병비` 문구와 간병 담보를 확인할 수 있는 간병인보험으로 반영합니다.

### 추천에 사용되는 보험 상품

| 카테고리 | 상품명 | 공식 출처 |
|---|---|---|

| 여성 건강 | 한화 시그니처 여성 건강보험 4.0(무) | 한화손보 캐롯 공식 홈페이지 |
| 화재 | 다이렉트 119주택화재보험 | 한화다이렉트 메인 |

| 여행 | 캐롯 해외여행보험 | 한화손보 캐롯 공식 홈페이지 |
| 종합 건강 | 한화 더건강한 한아름종합보험(무) | 한화 더건강한 한아름종합보험 상품 페이지 |

| 골프 | 다이렉트 홀인원보험 | 한화손보 캐롯 홀인원보험 페이지 |

## 주요 파일

- `src/faceAnalyzer.js`: `@vladmandic/human` 기반 브라우저 얼굴 추정 모듈
- `src/camera.js`: 카메라 시작/종료 및 오류 처리
- `src/utils/ageBucket.js`: 나이 → 연령대 변환
- `src/products.js`: 한화손보 상품 메타데이터
- `src/recommendations.js`: 규칙 기반 추천 상품 선택 및 추천 이유 생성
- `src/copy.js`: 화면 문구

## 백로그

### 표정 기반 테마 추천

- 얼굴 표정을 `활동형` / `안정형` / `기본형` 정도의 보조 테마로 분류합니다.
- 표정 결과는 상품을 새로 결정하는 1차 기준이 아니라 기존 나이·성별 추천 목록의 정렬 보정에만 사용합니다.
- 사용자 화면에는 `행복`, `슬픔`, `불안` 같은 감정 판정 문구를 직접 노출하지 않습니다.
- 표정 신뢰도가 낮거나 얼굴 방향 스캔 품질이 낮으면 기존 추천 순서를 유지합니다.
- 후보 매핑 예시:
  - 활동형: 여행, 운전자, 골프, 치아, 화재
  - 안정형: 실손, 종합 건강, 암, 여성 건강, 간병/노후

### 상품공시 전체 리스트 기반 상품 풀 확장

- 한화손보 `보험상품공시 > 현재판매상품` 페이지를 기준으로 추천 후보 상품을 재점검합니다.
- 현재 구현은 공식 메인/다이렉트/일부 상품 페이지·약관 PDF에서 선별한 상품만 사용하며, 상품공시의 전체 현재판매상품을 모두 반영하지는 않았습니다.
- 공시 페이지에서 확인되는 큰 상품군:
  - 자동차보험: 개인용, 업무용, 영업용, 기타
  - 장기보험: 화재, 상해/질병, 저축, 연금, 방카, 제도성특별약관, 인터넷, 장기간병
  - 일반보험: 화재, 상해, 종합, 기타특종, 책임, 방카
  - 퇴직연금
- 다음 확장 시 `저축`, `연금`, `장기간병`, `상해/질병` 상품 중 데모 추천 카드로 자연스러운 상품을 우선 검토합니다.
